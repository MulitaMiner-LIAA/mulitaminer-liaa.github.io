# MulitaMiner · Laboratório de IA Aplicada

Página do projeto desenvolvido na disciplina Laboratório de IA Aplicada
(UNIPAMPA, 2026): extração estruturada de vulnerabilidades a partir de
relatórios PDF de scanners, com o modelo de linguagem rodando dentro da
organização.

Autores: Beatriz Machado, Cristhian Kapelinski e Guilherme Klauberg.

Site estático (HTML, CSS e JavaScript puros), servido pelo GitHub Pages.
Sem etapa de build: abra `index.html` ou publique a raiz do repositório.

- `index.html`: a página, em português; o inglês vem de `assets/app.js`
- `assets/style.css`: estilos, tema claro e escuro
- `assets/app.js`: troca de idioma e tema, gráficos em SVG
- `assets/stages/`: ilustrações do pipeline
- `pdfs/`: as apresentações entregues na disciplina

Código da ferramenta: <https://github.com/INARI18/MulitaMiner2>.
